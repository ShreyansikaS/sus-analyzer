# SUS Analyzer

Scores System Usability Scale surveys and summarizes results for UX research reports.

**Live demo:** `https://YOUR-USERNAME.github.io/sus-analyzer/` (after enabling GitHub Pages)

## Features
- Paste or upload CSV of 10-item SUS responses
- Validates input with clear row-level errors
- Per-participant scores, mean, SD, min/max, letter grade
- Exports results as CSV

## Run locally
No build step. Open `index.html` in a browser.
